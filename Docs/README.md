# RTS Engine

A production-oriented RTS framework built in Godot 4.7.

## Goals

- Learn professional RTS architecture.
- Build reusable gameplay systems.
- Practice commercial-scale game development.

## Current Features

- RTS Selection
- Multi Selection
- Building Placement
- Ghost Buildings
- Command System
- Movement Component
- FSM Architecture

## Planned

- Harvest
- Inventory
- Combat
- AI
- Economy
- Multiplayer
- Save System

## Architecture

Managers coordinate systems.

Components implement behavior.

FSM controls unit states.

Base classes contain only shared logic.
