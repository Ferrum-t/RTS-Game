# Resource System Expansion Plan

## Цель
Добавить новые типы ресурсов в RTS-систему и поддержать их на уровне:
- игровых сцен ресурсов
- скриптов сборки/инвентаря
- сдачи в центр базы
- UI отображения

## Текущее состояние
- `BaseResource` имеет поле `resource_name`
- `InventoryComponent` теперь хранит ресурсы динамически
- `HarvestComponent` добавляет ресурсы по имени
- `TownCenter` принимает и суммирует словарь ресурсов
- `BuildPanel` отображает все хранящиеся ресурсы

## Шаги расширения
1. Создать новые ресурсные классы и сцены
   - например: `FiberResource`, `CrystalResource`, `OreResource`
   - каждая сцена должна наследоваться от `BaseResource`
   - задать `resource_name` для каждого типа

2. Обновить `BaseResource`/сцену ресурса
   - если нужно, добавить специфичную визуальную модель и звуки
   - экспортировать максимальное количество ресурса и имя типа

3. Обновить `TownCenter` (по необходимости)
   - добавить начальные складские значения для новых типов
   - убедиться, что словарь `stored_resources` поддерживает новые ключи

4. Обновить `InventoryComponent`
   - новая архитектура уже поддерживает динамические типы
   - при необходимости соединить дополнительные методы с UI/логикой

5. Обновить `BuildPanel` и другие UI-элементы
   - отображать все доступные ресурсы автоматически
   - показывать новые типы в панели выбранного юнита

6. Обновить контент
   - добавить сцены ресурсов в соответствующую папку
   - разместить их на карте (`Scenes/WorldObjects/Resources` или аналогично)

## Пример новых типов
- `Fiber` — растительный ресурс для постройки и технологий
- `Crystal` — редкий ресурс для продвинутого вооружения
- `Ore` — общий ресурс для металла и строительства

## Замечания
- Для Godot-сцен необходимо создать `.tscn` файлы через редактор
- Скрипты можно подготовить заранее, но визуальные Prefab/сцены удобнее редактировать в среде
