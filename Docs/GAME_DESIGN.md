# Nomad Wars

## Genre

RTS

## Theme

Post-apocalyptic Central Asia

## Visual Style

Stylized low-poly

## Inspirations

StarCraft II
Warcraft III
Age of Empires IV

## Core Gameplay

- Build a camp
- Gather resources
- Train units
- Expand territory
- Fight enemy tribes

## Technical Goals

- Modular RTS Framework
- Data-driven gameplay
- Component architecture
- Large-scale battles
- Easy content creation through Resources
